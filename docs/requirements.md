# Voice Input App — MVP 要件定義書

## 1. プロダクト概要

| 項目 | 内容 |
|------|------|
| プロダクト名 | Voice Input（仮称） |
| コンセプト | ワンクリックで日本語音声をテキスト化し、多言語翻訳も可能な個人用音声入力Webアプリ |
| 参考プロダクト | [Typeless AI](https://www.typeless.com/) |
| 対象ユーザー | 開発者本人（個人利用） |
| MVP目標 | 最小限の機能で「音声→テキスト→翻訳→コピー」の一連フローを完成させる |

---

## 2. MVP 機能要件

### 2.1 必須機能（Must Have）

| # | 機能 | 説明 |
|---|------|------|
| F1 | ワンクリック音声入力 | ボタン1つで録音開始/停止。デバイスマイクを使用 |
| F2 | 日本語音声認識 | 日本語の音声をリアルタイムでテキストに変換 |
| F3 | リアルタイム表示 | 認識中のテキストをリアルタイムでUI上に表示（interim results） |
| F4 | 多言語翻訳 | 認識したテキストを選択した言語に翻訳して表示 |
| F5 | テキストコピー | 認識結果・翻訳結果をワンクリックでクリップボードにコピー |
| F6 | 認識言語切替 | 入力言語を日本語以外（英語・中国語等）にも切替可能 |
| F7 | 翻訳先言語選択 | 翻訳先の言語をドロップダウンから選択 |

### 2.2 MVPスコープ外（将来対応）

- フィラーワード除去（「えーと」「あの」等）
- 自動フォーマット・句読点補正
- トーン自動調整
- 音声履歴の保存・管理
- PWA対応（オフライン）
- ユーザー辞書登録
- デスクトップネイティブアプリ化

## 3. 技術選定

### 3.1 必須コード言語・技術スタック

```
フロントエンド:  HTML5 / CSS3 / JavaScript (Vanilla)
音声認識:        Web Speech API (SpeechRecognition)
翻訳:           Google Translate API（無料枠）または LibreTranslate API
ホスティング:    GitHub Pages または Vercel (静的サイト)
```

### 3.2 技術選定理由

| 技術 | 選定理由 |
|------|---------|
| **Vanilla JS（サーバーレス構成）** | フレームワーク不要。HTML1ファイルで完結可能。ビルド不要で即デプロイ |
| **Web Speech API** | ブラウザ内蔵。無料。日本語含む100+言語対応。追加APIキー不要 |
| **Google Translate / LibreTranslate** | 翻訳品質が高い。無料枠で個人利用に十分 |
| **静的ホスティング** | サーバー管理不要。無料でデプロイ可能 |

### 3.3 制約事項

| 制約 | 内容 |
|------|------|
| ブラウザ制限 | Web Speech APIはChrome/Edge（Chromium系）でのみ完全動作 |
| ネットワーク必須 | 音声認識にインターネット接続が必要（Chromeの場合Googleサーバーに送信） |
| HTTPS必須 | マイクアクセスにはHTTPSまたはlocalhostが必須 |

## 5. ユーザーフロー

```
1. アプリを開く
2. 入力言語を選択（デフォルト: 日本語）
3. 🎤 ボタンをクリック → マイク権限を許可
4. 話す → テキストがリアルタイム表示
5. 🎤 ボタンを再クリック or 無音で自動停止
6. （任意）翻訳先言語を選択 → 翻訳結果が表示
7. コピーボタンでクリップボードにコピー
8. テキストを任意のアプリに貼り付けて使用
```

## 7. 翻訳API方針

### 選択肢A: MyMemory Translation API（推奨・MVP用）
- 無料（1日1000リクエスト）
- APIキー不要
- エンドポイント: `https://api.mymemory.translated.net/get?q={text}&langpair={from}|{to}`

### 選択肢B: LibreTranslate（セルフホスト可）
- オープンソース・完全無料
- セルフホストで制限なし
- 公開インスタンスは速度制限あり

### 選択肢C: Google Cloud Translation API
- 高品質だがAPIキーが必要
- 月50万文字まで無料
- 将来のスケールアップ時に検討

**MVP判断**: 選択肢Aを採用。APIキー不要・即利用可能。

## 8. 非機能要件

| 項目 | 要件 |
|------|------|
| レスポンス | 音声認識は200ms以内にUI反映 |
| UI | モバイル対応（レスポンシブデザイン） |
| プライバシー | ローカル処理優先。音声データの永続保存なし |
| アクセシビリティ | 大きなボタン、明確な状態表示（録音中/停止中） |
