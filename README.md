# FFF - Faint Fog Fantasy

**「不完全さの美学」を掲げた新しいSNSコンセプト**

写真をポリゴンやドット風に加工して投稿する、情報の断捨離を目的としたSNSアプリのデモ版です。

## コンセプト

- **Faint（微かな）**: 情報を絞り、本質だけを伝える
- **Fog（霧）**: 詳細を隠し、想像力を刺激する
- **Fantasy（幻想）**: 不完全さが生む独自の美しさ

## デモアプリの機能

### 実装済み

| 機能 | 説明 |
|------|------|
| 画像アップロード | タップまたはドラッグ&ドロップで画像を選択 |
| ポリゴン変換 | 三角形ベースの幾何学的な加工 |
| ドット変換 | 円形ドットによるレトロな加工 |
| ローポリ変換 | ランダムな三角形分割による芸術的な加工 |
| 解像度調整 | 5段階の粗さ調整 |
| 霧エフェクト | 濃さを調整可能な霧の演出 |
| ギャラリー | 投稿した画像の一覧表示 |
| ローカル保存 | LocalStorageによるデータ永続化 |

## 使い方

1. `fff.html` をブラウザで開く
2. 画像をアップロード
3. スタイル（ポリゴン/ドット/ローポリ）を選択
4. 解像度と霧の濃さを調整
5. 「投稿する」でギャラリーに追加

## 技術スタック

- **HTML/CSS/JavaScript**: フレームワーク不使用のバニラ実装
- **Canvas API**: 画像のリアルタイム変換処理
- **LocalStorage**: クライアントサイドのデータ保存
