# drive

iOSのローカル環境に保存して使える、HTMLファイル形式のTODOリスト管理ツールです。
ローカルファイルとして開くと、データは端末内のブラウザ(LocalStorage)に保存されます。
PCでも同じHTMLファイルをそのまま開いて利用できます。

## 使い方

1. `todo.html` をiPhone/iPadに保存します。
2. 「ファイル」アプリから `todo.html` を開きます。
3. タスクを追加・完了・削除できます。

### PCでの利用

- `todo.html` をVS Codeにコピペ保存して、そのままブラウザで開くだけで利用できます。
- 動作確認やデバッグ時に、VS Codeの拡張「Live Server」などで簡易サーバーとして開くと、
  保存先が安定しやすくなります。

## 機能

- タスク追加、完了、削除
- フィルタ（すべて / 未完了 / 完了）
- 完了タスク削除 / 全削除
- LocalStorageへの自動保存
