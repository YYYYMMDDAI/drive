# 画面分割アプリ要件定義書

## 1. 機能要件定義

### 1.1 概要
iPhone 13〜17で動作するPWA（Progressive Web App）型画面分割ツール。
Galaxy Z Foldのように、1つの画面を上下に分割して2つのWebサイトを同時表示できる。

### 1.2 コア機能

| 機能 | 説明 |
|------|------|
| 画面分割 | 上下2分割で2つのWebサイトを同時表示 |
| 分割バー | ドラッグで分割比率を調整（15%〜85%） |
| URL入力 | 各パネルにURLを入力してWebサイトを表示 |
| パネルクリア | 各パネルの×ボタンでコンテンツをクリア |

### 1.3 対応ネットワーク

| ネットワーク | 対応状況 |
|--------------|----------|
| LTE/4G | 完全対応 |
| 5G | 完全対応 |
| Wi-Fi | 完全対応 |
| オフライン | アプリ自体はオフライン動作可能 |

```
app/
├── index.html              # HTMLエントリーポイント
├── vite.config.ts          # Vite + PWA設定

    └── styles/

```

## 3. UI要件定義

### 3.1 レイアウト構成

```
┌─────────────────────────────────────┐
│                                     │
│  ┌─────────────────────────────┐   │
│  │                             │   │
│  │      上側パネル              │   │ ← Webサイト表示
│  │      （iframe）             │   │    または URL入力
│  │                             │   │
│  └─────────────────────────────┘   │
│                                     │
│  ════════════ ▬▬▬ ═══════════════  │ ← 分割バー（ドラッグ可能）
│                                     │
│  ┌─────────────────────────────┐   │
│  │                             │   │
│  │      下側パネル              │   │ ← Webサイト表示
│  │      （iframe）             │   │    または URL入力
│  │                             │   │
│  └─────────────────────────────┘   │
│                                     │
└─────────────────────────────────────┘
```

### 3.2 操作方法

| 操作 | 動作 |
|------|------|
| URLを入力して「開く」 | 指定URLのWebサイトを表示 |
| 分割バーをドラッグ | 上下の分割比率を調整 |
| ×ボタンをタップ | パネルのコンテンツをクリア |
| Enterキー | URL入力確定（開くと同等） |

### 3.3 カラーシステム

| 変数 | ライトモード | ダークモード |
|------|--------------|--------------|
| `--bg-primary` | #FFFFFF | #000000 |
| `--bg-secondary` | #F2F2F7 | #1C1C1E |
| `--text-primary` | #000000 | #FFFFFF |
| `--accent` | #007AFF | #0A84FF |

## 4. 運用要件定義

### 4.1 開発コマンド

```bash
npm run dev        # 開発サーバー起動
npm run build      # 本番ビルド
npm run preview    # ビルド結果プレビュー
npm run deploy     # Vercelデプロイ（限定公開）
```

### 4.2 iPhoneでの使用方法

1. デプロイURLをSafariで開く
2. 共有ボタン → 「ホーム画面に追加」
3. ホーム画面からアプリとして起動
4. 上下のパネルにURLを入力して使用

## 6. 制約事項

1. **iframe制限**: 一部のWebサイト（Google, Facebookなど）はX-Frame-Optionsにより表示不可
2. **クロスオリジン**: 異なるドメイン間のコンテンツ操作は不可
3. **ストレージ**: URL履歴の永続化は未実装（将来対応可能）
