# モバイルローカルツール要件定義書

## 1. 機能要件定義

### 1.1 概要
iPhone 13〜17で動作するPWA（Progressive Web App）型ローカルツール。
ネイティブアプリのようにホーム画面から起動し、オフラインでも完全動作する。

### 1.2 コア機能

| 機能 | 説明 | 実装状況 |
|------|------|----------|
| カウンター | 数値の増減・リセット | 実装済 |
| メモ入力 | テキスト入力・自動保存 | 実装済 |
| データ保存 | メモとカウンター値をペアで永続化 | 実装済 |
| データ一覧 | 保存データの表示・削除 | 実装済 |
| ネットワーク状態表示 | オンライン/オフライン検知 | 実装済 |

### 1.3 データ管理

| 項目 | 仕様 |
|------|------|
| 設定保存 | LocalStorage（同期的、軽量） |
| データ保存 | IndexedDB（非同期、大容量対応） |
| 永続性 | ブラウザキャッシュクリアまで保持 |
| 同期 | 将来的にバックエンドAPI連携可能 |

### 1.4 ネットワーク対応

| ネットワーク | 対応状況 |
|--------------|----------|
| LTE/4G | 完全対応 |
| 5G | 完全対応 |
| Wi-Fi | 完全対応 |
| オフライン | 完全対応（Service Worker） |

## 2. ファイル要件定義

### 2.1 ディレクトリ構造

```
app/
├── index.html              # HTMLエントリーポイント
├── vite.config.ts          # Vite + PWA設定
├── tsconfig.json           # TypeScript設定
├── package.json            # 依存関係
├── public/
│   ├── favicon.svg         # ファビコン
│   └── icon.svg            # PWAアイコン
└── src/
    ├── main.tsx            # Reactエントリーポイント
    ├── App.tsx             # メインアプリケーション
    ├── vite-env.d.ts       # Vite型定義
    ├── types/
    │   └── index.ts        # 共通型定義
    ├── services/
    │   ├── storage.ts      # ストレージ抽象化
    │   └── api.ts          # API抽象化
    ├── hooks/
    │   ├── index.ts        # エクスポート
    │   ├── useNetwork.ts   # ネットワーク状態フック
    │   ├── useData.ts      # データ管理フック
    │   └── useSettings.ts  # 設定管理フック
    ├── components/
    │   ├── index.ts        # エクスポート
    │   ├── NetworkStatus.tsx  # ネットワーク表示
    │   ├── Counter.tsx        # カウンター
    │   ├── MemoInput.tsx      # メモ入力
    │   └── DataList.tsx       # データ一覧
    └── styles/
        ├── global.css      # グローバルスタイル
        └── components.css  # コンポーネントスタイル
```

### 2.2 ファイル役割一覧

| ファイル | 役割 | 依存 |
|----------|------|------|
| `vite.config.ts` | ビルド設定、PWAマニフェスト生成 | vite, vite-plugin-pwa |
| `src/types/index.ts` | DataItem, AppSettings等の型定義 | なし |
| `src/services/storage.ts` | LocalStorage/IndexedDB操作 | types |
| `src/services/api.ts` | データCRUD、将来のAPI連携 | storage, types |
| `src/hooks/useNetwork.ts` | オンライン状態検知 | types |
| `src/hooks/useData.ts` | データ取得・作成・削除 | api, types |
| `src/hooks/useSettings.ts` | 設定の読み書き | storage, types |
| `src/App.tsx` | UIとロジックの統合 | hooks, components |

## 4. 運用要件定義

### 4.1 開発環境

| 項目 | 仕様 |
|------|------|
| Node.js | v18以上推奨 |
| パッケージマネージャ | npm |
| ビルドツール | Vite 7.x |
| 言語 | TypeScript 5.x |
| フレームワーク | React 19.x |

### 4.2 コマンド一覧

```bash
# 依存関係インストール
npm install

# 開発サーバー起動（ホットリロード）
npm run dev

# 本番ビルド
npm run build

# ビルド結果プレビュー
npm run preview

# Lintチェック
npm run lint
```

### 4.3 開発サーバーアクセス

| 環境 | URL |
|------|-----|
| PC（ローカル） | http://localhost:5173 |
| 同一LAN内iPhone | http://[PCのIPアドレス]:5173 |

### 4.4 iPhoneへのインストール手順

1. PC と iPhone を同一Wi-Fiに接続
2. PC の IP アドレスを確認（例: `ifconfig` または `ip addr`）
3. `npm run dev` で開発サーバー起動
4. iPhone Safari で `http://[IPアドレス]:5173` にアクセス
5. 共有ボタン → 「ホーム画面に追加」
6. ホーム画面から起動（フルスクリーン動作）

### 4.5 本番デプロイ

```bash
# ビルド
npm run build

# dist/ ディレクトリを任意のサーバーにデプロイ
# - Vercel
# - Netlify
# - Cloudflare Pages
# - 自前サーバー（nginx等）
```

### 4.6 将来のバックエンド連携

環境変数 `VITE_API_URL` を設定することで、自動的にリモートAPIに切り替わる。

```bash
# .env.local
VITE_API_URL=https://api.example.com
```

対応予定バックエンド:
- **Go**: net/http, Gin, Echo等
- **Node.js**: Express, Fastify等

### 4.7 PWA機能

| 機能 | 状態 |
|------|------|
| Service Worker | 自動生成（Workbox） |
| オフラインキャッシュ | 全静的ファイル |
| アプリアイコン | SVG（192x192, 512x512） |
| スプラッシュ画面 | iOS Safari対応 |
| 自動更新検知 | 有効 |

## 7. 制約事項

1. **ストレージ制限**: ブラウザの制限に依存（通常5MB〜無制限）
2. **プッシュ通知**: iOS PWAでは制限あり（iOS 16.4以降で一部対応）
3. **バックグラウンド処理**: iOS PWAでは制限あり
4. **App Store不要**: 開発者個人利用向け、審査なしで即デプロイ可能
